# CPP Module 03

## Overview
Inheritance, constructor/destructor chaining, and class extension patterns with trap hierarchy.

## Exercises
- ex00: ClapTrap
- ex01: ScavTrap
- ex02: FragTrap
- ex03: DiamondTrap

## Build and run
```bash
cd ex00 && make && ./ClapTrap
cd ../ex01 && make && ./ScavTrap
cd ../ex02 && make && ./FlagTrap
cd ../ex03 && make && ./DiamondTrap
```

## Notes
- Watch for shadowed fields and method overriding behavior.
- Keep constructors explicit and coherent across inheritance levels.
