# CPP Module 00

## Overview
Introduction to C++ basics, namespaces, classes, member functions, stdio streams and simple object design.

## Exercises
- ex00: Megaphone
- ex01: PhoneBook

## Build and run
```bash
cd ex00 && make && ./megaphone "hello" "world"
cd ../ex01 && make && ./phone_book
```

## Notes
- Follow canonical C++98 compilation flags from each Makefile.
- Keep memory management simple and explicit.
