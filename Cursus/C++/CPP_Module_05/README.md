# CPP Module 05

## Overview
Exception handling, try-catch blocks, and class hierarchy design — Bureaucrat grades, signable Forms, and an Intern factory.

## Exercises
- ex00: Bureaucrat
- ex01: Bureaucrat + Form
- ex02: AForm, ShrubberyCreationForm, RobotomyRequestForm, PresidentialPardonForm
- ex03: Intern

## Build and run
```bash
cd ex00 && make && ./Bureaucrat
cd ../ex01 && make && ./Bureaucrat
cd ../ex02 && make && ./newForms
cd ../ex03 && make && ./Intern
```

## Notes
- Follow canonical C++98 compilation flags from each Makefile.
- Keep memory management simple and explicit.
