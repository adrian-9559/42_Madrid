# C Piscine - C 02

## Introducción
Este módulo se centra en la manipulación de cadenas de caracteres en C. Aprenderás a copiar, comparar, transformar y analizar strings, así como a trabajar con memoria no imprimible. Estas funciones son esenciales para el procesamiento de texto y la interacción con datos de usuario.
