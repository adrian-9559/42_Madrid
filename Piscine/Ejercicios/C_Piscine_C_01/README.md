# C Piscine - C 01

## Introducción
En este módulo trabajarás con punteros y arrays en C. Aprenderás a manipular direcciones de memoria, pasar argumentos por referencia, y operar con arrays de enteros. Estos conceptos son fundamentales para entender el manejo de memoria en C y sientan las bases para estructuras de datos más complejas.

## Ejercicios

### [ex00: ft_ft](./ex00/ft_ft.c)
Escribe una función que tome un puntero a int y asigne 42 a la dirección apuntada.

### [ex01: ft_ultimate_ft](./ex01/ft_ultimate_ft.c)
Escribe una función que tome un puntero a puntero a puntero a int y asigne 42.

### [ex02: ft_swap](./ex02/ft_swap.c)
Escribe una función que intercambie los valores de dos enteros.

### [ex03: ft_div_mod](./ex03/ft_div_mod.c)

### [ex04: ft_ultimate_div_mod](./ex04/ft_ultimate_div_mod.c)
Escribe una función que reemplace los valores apuntados por la división y el módulo.

### [ex05: ft_putstr](./ex05/ft_putstr.c)
Escribe una función que imprima una cadena de caracteres en la salida estándar.

### [ex06: ft_strlen](./ex06/ft_strlen.c)
Escribe una función que cuente y devuelva la longitud de una cadena.

### [ex07: ft_rev_int_tab](./ex07/ft_rev_int_tab.c)
Escribe una función que invierta el orden de los elementos de un array de enteros.

### [ex08: ft_sort_int_tab](./ex08/ft_sort_int_tab.c)
Escribe una función que ordene un array de enteros en orden ascendente.
