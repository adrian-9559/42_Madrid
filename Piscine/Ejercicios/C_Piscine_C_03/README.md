# C Piscine - C 03

## Introducción
En este módulo profundizarás en la manipulación de cadenas con funciones de comparación y concatenación. Aprenderás a buscar subcadenas y a concatenar cadenas de forma segura utilizando límites de tamaño. Estas utilidades son fundamentales para el manejo eficiente de strings en C y forman parte de la biblioteca estándar.
