# C_Piscine_Rush_02

## Introducción
El tercer rush consiste en implementar un programa que convierta números a su representación textual en inglés. Dado un número (hasta 4 dígitos), el programa debe leer un diccionario y generar la traducción. Este ejercicio integra lectura de archivos, parseo, gestión de memoria y lógica de conversión numérica.

- Si tu programa no compila, tendrás un 0.
- No puedes dejar en tu directorio ningún archivo que no se haya indicado de forma explícita en los enunciados de los ejercicios.
